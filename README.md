# PXHVibe

MVP giao diện terminal cho ứng dụng vibe coding, xây dựng bằng TypeScript, React và Ink.

## Yêu cầu

- Node.js 20 trở lên
- npm

## Cài đặt

```sh
npm install
```

## Chạy development

```sh
npm run dev
```

## Build và chạy bản build

```sh
npm run build
npm start
```

## Phím điều khiển

- `Enter`: gửi prompt
- `Backspace` hoặc `Delete`: xóa ký tự
- `Ctrl+C`: thoát ứng dụng
